# Zornhub Arcade

A React + TypeScript arcade suite featuring the original West Korea basement games.

## Included Games & Modules

1. **Zim Clicker (Pervitin Clicker)**
   - Clicker mechanics harvesting pervitins for the Irken Empire.
   - The Zlack Zlarket: 11 upgrades with progressive scaling (Vero slaves, music labels, Poland, nuclear ass).
   - Las Vegas Slots: GIR's Slots and SUPER SLOTS OF DOOM with custom odds, multipliers, and confetti.
   - College Fund Drainer Casino: Coin Flip, Wheel of Mrs. Fortune, Number Go Up / Crash, and Bonk John Pork minigames.
   - Local storage save/load/reset.

2. **Romanian Simulator: Component Conquest**
   - Reverse-assembly PC theft simulation.
   - Strategic prerequisite logic: coolers before CPUs, toolkits for extra time, crowbars for PSUs, and safe extractions before Motherboard removal.
   - Hideout bank balance and shady goods upgrades shop.

3. **Battle Anyone: The Game**
   - Undertale & Deltarune inspired turn-based combat engine.
   - Custom enemy sprite upload, customizable health, personality, and dialogue generation.
   - Custom item forge (Healing, Defense, Attack boosts).
   - Dynamic typewriter dialogue, battle soundtrack, and fight/item turns.

4. **BLOOD//CIRCUIT**
   - Cyber-hell arena FPS with coin ricochet, grapple hook, shotgun parries, shockwaves, and Blood Forge meta progression.

5. **Culturekill & Arcade Lobby**
   - Retro CRT scanline visuals, video screening, and quick navigation.

## Development & Build

```bash
npm install
npm run dev     # Starts Vite dev server on port 3000
npm run build   # Production build
```
